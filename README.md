# InkedbyShiki

Webová stránka pre tetovacie štúdio InkedbyShiki, Horná Súča.

## Nasadenie na Vercel

1. Vytvorte nový repo na GitHub
2. Nahrajte tento projekt
3. Pripojte Vercel na GitHub repo
4. Vercel automaticky nasadí web

## Lokálny vývoj

Jednoducho otvorte `index.html` v prehliadači.

## Štruktúra

```
inkedbyshiki-project/
├── index.html          # Hlavný HTML súbor
├── vercel.json         # Vercel konfigurácia
├── .gitignore          # Git ignore súbory
└── README.md           # Tento súbor
```
